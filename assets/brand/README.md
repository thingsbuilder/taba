# Taba brand

| File | Use |
|---|---|
| `taba-mark.svg` | Mark on light backgrounds |
| `taba-mark-dark.svg` | Mark on dark backgrounds |
| `taba-app-icon.svg` | App icon, favicon, PWA icon (square, rounded corners) |
| `taba-mark-256.png` | Mark as 256×256 PNG with transparent background, for places that do not accept SVG (Unico console logo) |

The mark is a ring of six *ocas* (houses) around a center: the layout of a *taba*, the Tupi word for village.

## Colors

| Name | Hex | Use |
|---|---|---|
| Teal | `#0F5C5A` | Mark on light backgrounds, app icon background |
| Teal light | `#4FB3AA` | Mark on dark backgrounds |
| Urucum | `#D9622B` | Center of the mark on light backgrounds |
| Urucum light | `#E9834A` | Center of the mark on dark backgrounds and on the app icon |
| Sand | `#F4EEE4` | Light background; mark on the app icon |
| Ink | `#1C2321` | Text and dark background |

Wordmark: "taba", lowercase, [Outfit](https://fonts.google.com/specimen/Outfit) Bold, letter spacing −2 at 72 px.

Do not use red with white, and never a cross: the red cross is a legally protected emblem.
